# Лабораторная работа №1: Алгоритм обучения персептрона

## 📋 Описание
Реализация классического персептрона Розенблатта для разделения двух классов. 
Персептрон обучается на данных 18 варианта и учится проводить разделяющую линию.

## 🎯 Задача
Обучить персептрон правильно классифицировать точки из таблицы варианта 18.
Функция активации - пороговая (значения -1 и +1).

## 🔧 Как это работает
1. Персептрон получает на вход вектор [1, x2, x1] (1 - это bias)
2. Считает взвешенную сумму: z = w0*1 + w1*x2 + w2*x1
3. Если z < 0, возвращает -1, иначе +1
4. Если ответ не совпал с правильным, веса корректируются

## 📊 Результаты
- **Количество примеров:** 36
- **Начальные веса:** [0.2, -0.3, 0.1]
- **Скорость обучения:** 0.1
- **Эпох до сходимости:** зависит от данных

## 🖼️ Визуализация
- Синие точки (_) - класс -1
- Красные точки (+) - класс +1
- Цветные линии - разделяющие границы на разных эпохах

## 📝 Заметки
Bias (w0) всегда умножается на 1, это смещение разделяющей линии

Веса обновляются только при ошибке

Примеры подаются в случайном порядке для лучшего обучения
