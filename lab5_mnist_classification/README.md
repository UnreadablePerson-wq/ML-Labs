# Лабораторная работа №5: Классификация MNIST

**Тема:** Распознавание рукописных цифр с помощью двухслойной нейронной сети и обратного распространения ошибки

## 🎯 Цель работы

Разобраться в механизмах работы искусственных нейронов, самостоятельно обучить модель методом обратного распространения ошибки и проанализировать влияние гиперпараметров и аугментации на точность классификации.

## 🧠 Архитектура сети

- **Входной слой:** 784 нейрона (28×28 пикселей) + bias
- **Скрытый слой:** настраиваемое количество нейронов (по умолчанию 64) с активацией `tanh`
- **Выходной слой:** 10 нейронов (по числу цифр) с активацией `sigmoid`

## 📊 Эксперименты

В работе проведены три эксперимента:

1. **Базовая модель** (LR=0.05, H=25) — исходная конфигурация
2. **Улучшенная модель** (LR=0.01, H=64) — подобранные гиперпараметры
3. **Модель с аугментацией** — улучшенная модель + расширение данных сдвигами

## 🔬 Аугментация данных

Для каждого изображения создаются 4 дополнительные копии со сдвигом на 1 пиксель:
- влево
- вправо
- вверх
- вниз

Размер обучающей выборки увеличивается в 5 раз (с 60 000 до 300 000 примеров).

## 📈 Результаты

| Модель | Точность на тесте |
|--------|-------------------|
| Базовая (LR=0.05, H=25) | 93.97% |
| Улучшенная (LR=0.01, H=64) | 98.28% |
| Улучшенная + аугментация | **98.91%** |
