## 📊 О датасете MNIST
MNIST (Modified National Institute of Standards and Technology) - это база рукописных цифр, которая стала классическим датасетом для машинного обучения.

**Характеристики:**
- 70000 изображений цифр от 0 до 9
- 60000 обучающих примеров, 10000 тестовых
- Размер каждого изображения: 28×28 пикселей (784 пикселя)
- Каждый пиксель имеет значение от 0 до 255 (градации серого)
- Цифры центрированы и нормализованы по размеру

**Особенности датасета:**
- Разный почерк у разных людей
- Разная толщина линий
- Небольшой наклон и сдвиг
- Шум на некоторых изображениях

## 🧠 Архитектура нейронной сети

Сеть состоит из трех слоев:

### 1. Входной слой (784 нейрона)
- Каждый нейрон соответствует одному пикселю изображения
- Значения нормализованы к диапазону [0, 1]

### 2. Скрытый слой (64 нейрона)
- Функция активации: tanh (гиперболический тангенс)
- Причина выбора: tanh дает значения в диапазоне [-1, 1], что помогает бороться с затуханием градиента
- 64 нейрона - компромисс между точностью и скоростью обучения

### 3. Выходной слой (1 нейрон)
- Функция активации: сигмоида
- Выход интерпретируется как вероятность того, что на изображении цифра 8
- Порог принятия решения: 0.5

**Схема сети:**
Вход (784) → [w1, b1] → tanh → Скрытый слой (64) → [w2, b2] → сигмоида → Выход (1)

## 🔧 Алгоритм обучения

### Прямой проход (forward pass)
1. На вход подается вектор из 784 значений
2. Вычисляется z1 = X·w1 + b1
3. Применяется tanh: a1 = tanh(z1)
4. Вычисляется z2 = a1·w2 + b2
5. Применяется сигмоида: a2 = sigmoid(z2)

### Функция потерь
Используется среднеквадратичная ошибка (MSE):
Loss = (a2 - y)²

где y - правильный ответ (1 для цифры 8, 0 для остальных)

### Обратное распространение (backpropagation)
1. Вычисляем градиент на выходе: d_output = 2*(a2 - y) * sigmoid'(a2)
2. Распространяем ошибку на скрытый слой: d_hidden = d_output·w2.T * tanh'(a1)
3. Обновляем веса: w -= learning_rate * (входы·градиент)

## 🔍 Анализ ошибок
Сеть чаще всего ошибается в следующих случаях:
1) Цифра 8, написанная с разрывом (похожа на 3 или 9)
2) Цифра 8 с очень тонкими линиями
3) Сильно наклоненные восьмерки
4) Цифры 6 и 9, написанные похоже на 8
5) Зашумленные изображения

## 📚 Теоретическая справка
```
Функции активации
Tanh (гиперболический тангенс):

Формула: tanh(x) = (e^x - e^(-x))/(e^x + e^(-x))

Диапазон: [-1, 1]

Производная: 1 - tanh²(x)

Преимущество: центрирована около нуля

Сигмоида:

Формула: sigmoid(x) = 1/(1 + e^(-x))

Диапазон: [0, 1]

Производная: sigmoid(x) * (1 - sigmoid(x))

Преимущество: выход можно интерпретировать как вероятность

Инициализация весов
Веса инициализируются случайными числами из нормального распределения с масштабом 0.1. Это важно для симметрии начального состояния.

Обновление весов
Используется стохастический градиентный спуск (SGD) с обновлением после каждого примера.
```
